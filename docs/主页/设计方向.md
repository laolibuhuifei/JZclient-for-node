# 主页设计方向

JZClientForNode 主页围绕“选择手表，查看位置与设备资料”组织。视觉采用 Material Design 3 的圆角、色调层次和导航形式，参考 FlClash 的简洁程度；实现继续使用项目现有的 React 组件。该主页已经成为全站设计基准，其配色、原字体、基础控件、导航和弹窗同步到其他业务页。

## 布局

桌面左侧保留主导航，导航项使用 16px 圆角矩形；显示 JZClientForNode 品牌的顶栏在滚动时固定于顶部。正文标题右侧放每日一言和刷新入口，最右侧右对齐排列家长账号、消息连接、OneBot 三个胶囊。每个胶囊左边保留功能图标，右边用绿色圆形勾或红色圆形叉表示状态；具体状态供悬停与读屏查看。

桌面正文第一行左侧放“我的手表”，承载设备选择和地图；右侧放“运行状态”，展示运行时长、CPU 和内存。宽度至少 1000px 的横屏下，“面板运行环境”接在右侧运行状态下面，两张右侧卡片同时撑高，加上中间 20px 间隔，总高度与左侧“我的手表”齐平；竖屏或更窄的窗口中，运行环境放在页面底部。设备资料改为按需查看：每张手表选择卡的名称右边有一个小圆形信息按钮，点击后打开“手表设备信息”弹窗，显示这台手表的 watchId、IMEI、号码、固件及补充资料，保留“设备详情”入口。查看资料不改变当前选中的手表。

运行状态增加系统 CPU 和系统内存两张原生 SVG 折线图，沿用 `/api/system` 每三秒轮询的成功响应采样。初始只显示当前真实数值和“正在采集趋势”，形成有效线段后再画曲线，不画孤立点或末端圆点，不生成历史；最多保留 41 个采样点及最近两分钟的记录。缺失值使对应曲线断开，不当作零值；请求失败保留已有曲线且不追加采样，恢复后的第一个成功点另起一段，短暂一次轮询失败也不会跨过中断连线。切换手表不重置趋势，后端进程重启后清空并重新采集。新成功采样用约 420ms 连续动画移动，快速刷新从当前帧接续；隐藏、离屏或减少动态效果时停止动画并直接呈现最终位置。未登录与账号失效空态采用账号轮廓图标。

“我的手表”直接显示两张设备选择卡，电量环靠卡片右侧对齐，型号右边是圆角矩形状态角标。名称超过五个字符或可用宽度时省略，完整名称保留为可访问名称及悬停提示。不再重复显示“当前手表”概览。超过两台时，两张卡片同时缩窄，为最右侧竖向圆角按钮留出空间；按钮使用向下箭头与剩余数量，展开可滚动的原生浮层。选中的额外设备会回显到主卡片中。

仅一台手表时，主页选择卡最大宽 320px 并靠右，不横向拉满地图上方空间。

每张主卡片自身宽度不超过 170px 时，使用 84px 高的扁卡片，隐藏圆环，改在右上角显示电量数字，并用沿卡片圆角描边的进度线表示电量，给名称和信息按钮留出空间。描边以左上角为起点，电量降低时沿顺时针方向逐段消失。可用宽度充足的主卡片和更多列表仍使用圆环，只有一台手表时也按卡片自身宽度判断。`0%` 显示零值且没有已填充进度，未知电量显示 `—`，两种状态保持区别。

选择卡下方直接显示定位地图，高度为宽桌面 480px、平板和中等桌面 400px、手机 320px。地图展示最近上报位置、地址与时间，保留刷新与“打开定位页”。第二行并排显示常用功能和最近公告。紧凑的“面板运行环境”默认展示系统架构、Node.js、处理器与主机名；点击“进程与账号详情”向下打开可滚动的原生浮层，详情不参与卡片布局，环境和状态卡片的高度保持不变。页面底部空间不足时，在页面末尾提供临时留白并滚动触发按钮，浮层关闭或组件卸载后删除留白。浮层支持 Escape、点击外部及关闭按钮，关闭按钮与 Escape 返回触发控件焦点。页面只渲染一份运行环境，由响应式布局决定它位于横屏右侧还是竖屏与窄屏底部。账号过期时详情中的 `mobileId` 与账号身份不展示缓存值。页脚居中显示原有 Node.js 吉祥物与 `powered by laolibuhuifei`，保留作者主页链接。

手机采用单列，标题区的三个胶囊另起一行，保留左图标和右状态图标；胶囊内容以固定小间距排列，文字与结果图标之间不使用自动外边距撑开。内容先显示“我的手表”和地图，再显示运行状态、常用功能、公告及底部运行环境。设备选择仍使用两张卡片和更多浮层，浮层高度为底部导航留出空间；主卡片和更多列表都可从名称旁查看设备资料。底部保留五个 MD3 导航位置和系统安全区域。一言仍以小字放在标题右侧。

插件管理作为独立主导航，可用插件应用继续追加为独立入口，桌面和平板侧栏可向下滚动查看全部内容。手机第五个导航位置为向上箭头“更多”，向上打开固定标题、仅列表滚动的浮层，容纳“我的”、“插件”管理和全部可用应用。主页第二行“插件”直接进入管理页；“我的”插件板块仍保留全部可用应用与管理入口。

其他需要设备选择的业务页把选择控件放到标题右侧，默认两张 64px 高的小矩形卡，超过两台由右侧按钮向下展开其余设备。单台固定桌面 165px、手机 150px 宽；标题保持一行，说明与操作在下一行。手机信息按钮放在卡片右下角并保留 44px 操作区域，名称省略、状态角标和电量数字分开排列。两种版本共享资料弹窗，查看信息不会改变当前设备。

## 字体与颜色

- 保留「送给猫咪的一本书」字体 `JZCatBook`。正文基准 17px，辅助文字以 14–15px 为主，标题 22–34px。
- 浅色模式使用偏冷的浅灰画布、白色卡片和柔和靛蓝强调色；深色模式使用深灰画布与浅靛蓝强调色。
- 默认进入深色，仅提供浅色与深色切换；已保存的浅色选择保留，旧自动主题值按深色处理，访问验证页遵循同一规则。
- 选中设备有底色和描边，常规宽度显示勾选标记；设备在线状态使用文字角标，三个连接胶囊使用勾或叉，具体状态保留给悬停与读屏。
- 常规电量圆环由原生 SVG 绘制，百分比居中；窄容器内的主卡片改用右上角数字和圆角边框进度线。`0%` 与未知值分别显示，低电量使用警告色。
- 主控件保持至少 44px 点击区域，键盘焦点可见。加载、无设备和接口错误都有对应状态。
- 切换设备内容和页面时使用 180ms 的淡入与小幅位移。数据刷新保持当前内容，不重播切换动效；开启“减少动态效果”时停用这些动画。
- 主导航与共享 Tabs 选中背景用 200ms 滑动指示层，中途切换从当前可见位置接续；首次或布局变化直接定位，页面隐藏、离屏和减少动态效果时取消移动。

## 实现约束

已安装 [ibelick/ui-skills](https://github.com/ibelick/ui-skills)，设计采用 `baseline-ui`、`fixing-accessibility` 和已指定的 `design-taste-frontend`、`impeccable` 的适用规范，复用 `Card`、`Button`、`Badge`、`Modal`、`PageHeader`、`EmptyState`、`Skeleton` 等组件。设备选择与信息按钮为独立控件，避免按钮嵌套；弹窗支持键盘操作、Escape 关闭和关闭后焦点返回。更多手表与进程详情使用浏览器原生 Popover。主页排布单独由主页样式控制，配色与基础控件已迁移到根元素全局主题，所有业务页及 `body` 弹窗共同继承；页面过渡、吸顶顶栏和作者页脚由公共外壳处理。

设备、账号、聊天、定位、扩展和诊断功能继续使用原有接口与路由。更多主页交互说明见 [新版主页设计说明](../../docs/主页/新版主页设计说明.md)，其他页面排布见 [全站 MD3 重构说明](../../docs/界面设计/全站MD3重构说明.md)。

主页“安全区域”继续携带当前设备进入守护页。新增危险区域使用地点搜索和地图选中心，默认半径 300 米，经纬度仅供确认；原接口只保存中心与半径，常见区域保持只读。坐标来源与未完成的硬件验证边界见 [地点搜索与地图选择](../../docs/安全区域/地点搜索与地图选择.md)。
