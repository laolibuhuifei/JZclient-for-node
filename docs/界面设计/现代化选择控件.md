# 现代化选择控件：单选、分段与开关

共享控件沿用原字体 `JZCatBook` 与全站 MD3 角色。单选字段、分类 Tabs 和启禁开关各自保留清晰的语义，用同一套选中底色、焦点描边和短暂反馈减少页面之间的差异。业务页面继续通过 [ui.tsx](../../frontend/src/components/ui.tsx) 使用它们。

## 单选字段

共享 `Select` 接入 [MDSelect.tsx](../../frontend/src/components/MDSelect.tsx)。可见控件是只选择选项的 combobox 按钮，显示当前名称和下拉箭头；点击后打开挂载到 `body` 的原生 Popover，内容使用 listbox 和 option 语义。它提供单选菜单，不包含文本搜索或多选功能。

| 部分 | 视觉约定 | 操作含义 |
| --- | --- | --- |
| 字段按钮 | 默认至少 52px 高，继承表单字号与 12px 圆角；长值省略 | 显示已选名称，箭头表示菜单状态 |
| 选项 | 至少 48px 高、16px 正文 | 点击后应用该值并关闭菜单 |
| 已选项 | 主色容器、对应前景色与勾 | 表示已保存到字段的当前值 |
| 活动项 | 独立焦点描边 | 表示键盘正在指向的选项，移动本身不提交 |
| 分组标题 | 13px 辅助文字 | 保留 `optgroup` 名称，分组禁用时跳过其中选项 |
| 菜单 | 12px 圆角、最大约 320px 高，内部滚动 | 根据可用空间向下或向上展开，限制在视口内 |

菜单打开时将当前值或首个可用选项作为活动项，长列表会把活动项滚入可见范围。滚动或窗口变化重新定位菜单，减少被页面边缘遮挡的情况。箭头旋转和菜单进入使用短暂反馈，减少动态效果模式停用这些动效。

## 键盘与字段契约

| 情况 | 按键 | 行为 |
| --- | --- | --- |
| 菜单关闭 | 上下方向键、Enter、Space | 打开菜单 |
| 菜单打开 | 上下方向键、Home、End | 移动活动项，跳过禁用项 |
| 菜单打开 | Enter、Space | 提交活动项并关闭 |
| 菜单打开 | Escape | 关闭并返回字段按钮，保留原值 |
| 菜单打开 | Tab | 关闭菜单，继续正常焦点顺序 |
| 菜单打开 | 输入字符 | 在约 700ms 的输入窗口内按名称前缀定位选项 |

原生 `select` 作为隐藏字段保留。`value`、`defaultValue`、`name`、`required`、`disabled`、转发 ref 和原有 `onChange` 仍从共享接口传入；选项值按字符串处理，`option` 与 `optgroup` 保留。选择后更新原字段并派发冒泡 change 事件，已有表单序列化和 `FormData` 继续读取该字段。

required 校验失败时，仅表单首个无效字段打开菜单并将焦点放到可见的 combobox 按钮。表单同时有多个必填字段时，后续 invalid 事件不抢走首个字段的焦点；修正后再次验证，再处理下一项。禁用字段不可打开或提交。

## 分段 Tabs

共享 Tabs 复用 [useSlidingIndicator.ts](../../frontend/src/components/useSlidingIndicator.ts)，选中底色用约 200ms 的滑动指示层在选项间移动，缓动为 `cubic-bezier(0.22, 1, 0.36, 1)`。指示层只由 Web Animations API 驱动，停用额外 CSS 子过渡。首次显示和布局变化直接定位；快速切换从当前可见位置接续，选中项自动滚入可见区域。页面隐藏、指示层离屏或减少动态效果时停止过渡，卸载清理观察器与动画。

Tabs 只有当前项使用 `tabIndex=0`。左右方向键、Home 和 End 切换并跳过禁用项，标签与选中状态保留原语义。设备设置、集成分类与其他使用共享 Tabs 的页面采用同一规则。

## 启禁 Toggle

Toggle 使用 checkbox 与 `role="switch"`，完整标签提供可访问名称。轨道为 52×32px，并保留至少 44px 操作区域；checked 状态来自已保存数据，不能仅用颜色表达含义。

插件管理页用 Toggle 表示单个插件启禁：`checked` 对应 `!plugin.disabled`。操作请求提交明确的启用或禁用目标，忙碌和插件系统关闭时禁用，失败后重新读取已保存状态。安装、配置、重载与带确认的卸载继续使用既有功能。

管理和应用入口使用 Puzzle 图标，只有应用另带“插件”标签。桌面与手机“更多”列表中名称和标签同行，标签不缩小，长名称在剩余空间省略；768–1179px 的方卡将标签固定在图标右上方，图标稍左移留出绘制间距，名称居中单行，完整名称保留在按钮 title，避免标签挤入名称行。手机图标恢复居中，名称与标签位置保持。

## 子浮层与弹窗

单选菜单和半径信息提示是非模态子浮层。嵌在表单 Modal 中时，Escape 先关闭当前子浮层并回到它的按钮，外层编辑仍保持；菜单选择只更新表单字段，最终保存由外层提交操作决定。半径提示仅解释范围，不能代替区域保存或新建弹窗。

时间字段通过共享 `TimePicker` 提供桌面转盘与手机滚轮，完整交互见 [时间选择说明](../../docs/界面设计/时间选择说明.md)。保存或媒体发送期间禁用相关控件，关闭权限变化不重新初始化弹窗焦点。
