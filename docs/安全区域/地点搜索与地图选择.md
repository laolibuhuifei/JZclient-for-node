# 安全区域：地点搜索与地图选择

安全区域页保留原九项守护状态、常见区域和危险区域列表。本次改造的是新增危险区域的交互：用地点搜索或地图选择中心，再设置半径，用户无需手工输入经纬度。常见区域继续只读，已有危险区域的删除接口与确认流程保留。

2026-11-16 已补齐平台要求的真实区域截图和至少三个边界点：界面仍选中心与半径，后端生成地图 PNG 与 24 点边界。具体字段、回归和实际保存验证范围见 [区域截图与提交修复](../../docs/安全区域/区域截图与提交修复.md)。

## 界面与操作流程

新增弹窗使用全站 MD3 配色、原字体 `JZCatBook` 与共享字段、按钮、Modal。默认半径为 300 米，选点地图约 360px 高，手机按可用宽度排列；地图提供高德普通地图与卫星影像切换。

| 步骤 | 用户操作 | 界面反馈 |
| --- | --- | --- |
| 搜索地点 | 输入城市、学校或地点名称，点击搜索或按 Enter | 显示读取状态，返回最多八条名称和地址 |
| 选择中心 | 点击搜索结果，或直接点击地图 | 地图显示选中标记，定位到结果并预览圆形范围 |
| 调整中心 | 拖动地图后点击“使用地图中心” | 将当前地图中心设为区域中心；拖动本身不自动保存选点 |
| 设置范围 | 修改以米为单位的半径 | 选中中心周围的圆形范围同步变化 |
| 确认保存 | 核对地点、只读坐标与半径后提交 | 使用原危险区域新增接口，成功后刷新区域列表 |

地图初始中心优先使用当前手表最近位置；没有有效位置时使用上海的示意视图。初始视图不等于已选区域，尚未选择时不显示区域标记或范围，保存按钮也不可用。坐标只用于确认，不提供编辑经纬度的输入框。

搜索支持 2–80 字符的模糊关键词。结果展示名称与地址，方便区分同名地点；若没有结果，可补充城市或改用地图选点。结果为空、上游失败、读取中、取消和重试均有独立反馈。修改关键词、取消搜索或关闭组件会取消旧请求，迟到响应不能覆盖新结果或重新写回已关闭的弹窗。

键盘可在搜索框按 Enter 发起搜索，中文输入法确认候选时不会误触发。方向键下可从输入框进入结果，结果支持上下、Home、End 导航；原生结果按钮支持 Enter 选择。地图可聚焦，方向键移动、加减键缩放，Enter 选择地图中心。保存期间禁用整个字段区域和关闭操作，失败后保留选择供重试。

半径标题旁保留小信息按钮，点击按需显示“以所选地点为中心，地图圆圈显示区域范围。”说明使用原生非模态 Popover，在视口内向上或向下定位，最大宽约 310px。点击外部关闭；Escape 只关闭当前提示并返回信息按钮，保留外层区域编辑弹窗。保存忙碌或禁用时关闭提示，滚动和窗口变化重新定位。

## 普通、卫星与地图缩放

共享 `TileMap` 默认显示普通图层，工具区的“普通 / 卫星”按钮用选中状态和勾表示当前图层。图层切换保留地图中心、缩放级别与已选地点，地图标记和区域范围仍沿同一坐标网格定位。

| 图层 | 瓦片来源 | 坐标网格 |
| --- | --- | --- |
| 普通 | 高德 `webrd`，`style=8` | 现有 GCJ-02 地图网格 |
| 卫星 | 高德 `webst` 真实影像，`style=6` | 同一 GCJ-02 地图网格 |

缩放范围为 3–19 级。按钮与键盘围绕当前中心缩放，滚轮以指针指向的地图位置为锚点；约 260ms 的连续过渡从当前可见状态开始，快速重复操作接续当前帧。瓦片、标记、范围圆圈与点选命中由同一实时视图驱动，相关 raster、tile、标记、中心目标与圆圈均不叠加 CSS 过渡，避免计算几何拖后当前帧。过渡中使用分数缩放，瓦片请求使用整数级。

已加载的旧瓦片以有限列表重投影为背景；当前目标瓦片全部就绪且动画结束后，才替换同来源的基础图层，减少缩放中的空白。远距离快速缩放只生成当前视图相邻的栅格级别，不枚举巨大远端图层；图像状态缓存裁剪时保留当前主图层与背景的可见键。卫星加载失败显示可重试或切回普通的提示。页面隐藏、地图离屏、禁用或减少动态效果时停止过渡，卸载清理动画与监听。拖动和点击选点继续区分，地图中心按钮与 Enter 选点保留。

## 与聊天位置共用选点

`GuardPlacePicker` 默认 `purpose="area"`，用于区域中心和半径预览。聊天位置弹窗使用 `purpose="message"`，标题与提示改为“选择发送位置”，复用同一搜索、取消、结果选择、地图点击和地图中心流程；只有区域模式在已选地点周围显示半径圆圈。

聊天选点不保存区域。位置消息在外层“发送位置”确认时才提交原 `location` 的 `latitude`、`longitude` 与 `poi`；没有选点时禁止发送，取消只关闭，失败保留所选地点。详见 [手机布局与消息状态](../../docs/聊天/手机布局与消息状态.md)。

## 原接口保存什么

浏览器仍使用 `POST /api/watch/{watchId}/guard/danger`，向本地后端发送以下三项：

```ts
{
  latitude: selectedPlace.latitude,
  longitude: selectedPlace.longitude,
  radius
}
```

地点名称和地址属于选点确认信息，不传入原接口，也不新增名称、地址或坐标系字段。中心必须是范围内的有限坐标，纬度为 −90 至 90、经度为 −180 至 180；半径必须是有限正数。后端同样校验这三项，不能依赖前端按钮禁用来保证有效数据。

本地后端随后生成真实地图截图，并把圆周转换为 32 个 `x/y` 边界点，以 `watchId`、`mapType:0`、`areaPic` 和 `areaDetail` 调用平台 `/allDayGuard/addDangerArea`。平台要求多边形边界，不能直接提交单个中心点加半径；截图或边界生成失败时不调用平台新增接口。

删除仍使用 `DELETE /api/watch/{watchId}/guard/danger/{areaId}`。没有新增区域编辑接口，也不改变常见区域的读取契约。

## 搜索服务与坐标流

地点搜索经过 WebUI 现有鉴权，入口为只读 `GET /api/map/search`。请求包含 `q`，可选的 `latitude` 与 `longitude` 必须成对有效；地图中心作为搜索位置偏向，不表示搜索只能落在该中心附近。

服务优先查询 [Photon](https://photon.komoot.io/)，空结果或失败时回退 [Nominatim](https://nominatim.openstreetmap.org/)，不要求用户配置第三方 key。结果以最多八条有效地点返回，包含名称、地址、中心坐标、搜索来源和坐标系标记。

| 环节 | 坐标约定 | 处理 |
| --- | --- | --- |
| 公开搜索结果 | WGS-84 | 后端归一化并转换为 GCJ-02 |
| 传给上游的搜索偏向 | WGS-84 | 当前地图中心从 GCJ-02 反算后发送 |
| WebUI 搜索结果 | `coordinateSystem: 'gcj02'` | 前端只接受标记一致且坐标有效的结果 |
| 高德地图选点 | 沿现有地图坐标流 | 点击位置或地图中心直接用于标记与范围预览 |
| 危险区域提交 | 沿现有接口的三字段坐标流 | 发送经纬度和半径，不额外转换已有手表位置 |

转换只作用于公开搜索结果和搜索偏向，不批量改写已保存区域或手表上报位置。搜索结果保留 `sourceCoordinateSystem: 'wgs84'` 与 provider，便于辨认来源。

仓库尚未证实官方手表危险区域 `mapType:0` 的坐标定义。当前实现让图示与提交沿现有地图坐标流保持一致，但未向真实手表新增区域或执行硬件定位验证；不能据此认定实际手表端的区域中心已经准确。真实设备验证应分别核对搜索地点、地图选点和手表端显示的同一位置。

## 请求生命周期与运行方式

搜索服务只访问固定 HTTPS 主机 Photon 与 Nominatim。上游只收到服务标识、JSON 接受类型和语言首选项，不转发本地 Cookie 或 Authorization。每次上游默认七秒超时，响应限制为 512KiB；结果缓存三分钟，最多一百项，同一关键词与近似中心合并请求，最多八个不同搜索同时等待，每个 provider 至少间隔一秒发起请求。

取消一个搜索调用不会取消仍被其他调用等待的共享请求；最后一个等待者取消时，才中止相应上游读取。前端同时用 AbortController 和请求身份防止旧结果覆盖当前状态。

开发入口为 [Vite 实时预览](http://127.0.0.1:5173/#/guard)。搜索 GET 由前置中间件处理，先通过运行中 `8787` 的 `/api/auth/status` 复用本地鉴权；`/api/map/search` 和尾斜杠形式 `/api/map/search/` 都由此桥接，原 API 代理显式排除这两个精确路径，其余接口继续走原代理。开发搜索拒绝非 GET 请求和未授权访问。

外置 CommonJS 搜索服务加入 Vite 配置依赖和文件监听，配置重载时清理模块缓存并重新建立中间件，让搜索源文件修改后不会继续使用旧桥接。此处理同时修复用户遇到的“接口不存在”路由问题。

直接 WebUI 后端已按原 `bin/webui.js` 入口重新加载，`8787` 当前服务已包含生产搜索路由；`5173` 开发进程和热更新继续保留。实际已登录浏览器分别通过两个入口查询公开地点“上海图书馆”，均返回五条 Photon / GCJ-02 结果。这里验证的是只读搜索接入，不包含真实危险区域新增或手表硬件坐标验证。
