# 时间选择：桌面时钟转盘与手机滚轮

闹钟与设备设置的时间字段统一使用 `TimePicker`，沿用原字体 `JZCatBook` 和 MD3 颜色。所有可见字段均为至少 52px 高的时间按钮：桌面打开时钟转盘，手机或粗指针触屏打开小时、分钟两列滚轮。可见原生时间输入已替换，隐藏原生字段继续承担表单关联与校验，设备接口格式保持一致。

## 桌面时钟转盘

弹窗默认显示小时和分钟两个数字段、时钟圆盘、操作提示与底部取消/确定。数字段采用约 44px 等宽数字，当前阶段使用主色容器；约 280px 的圆盘使用表面色、主色指针与圆形选中区域。外圈数字约 21px，内圈约 16px，保留 24 小时制。

| 阶段 | 显示范围 | 选择方式 |
| --- | --- | --- |
| 小时外圈 | 12、1–11 | 点击数字或拖动指针到外圈 |
| 小时内圈 | 00、13–23 | 点击数字或拖动指针到内圈 |
| 分钟 | 00–59 | 点击或拖动到任意分钟，常规数字刻度每五分钟显示 |
| 数字输入 | 两位小时、两位分钟 | 用底部键盘图标切换，输入后可返回转盘 |

完成小时选择后自动进入分钟，也可点击上方数字段切换阶段。选中不是五的倍数的分钟时，该分钟数字也会显示。指针拖动使用 pointer capture，拖动到圆盘边缘仍保持选择过程。

圆盘可聚焦并使用 slider 语义。方向键逐单位调整，Home 到 0，End 到该阶段最大值；PageUp/PageDown 以小时三格或分钟五格调整，Enter/Space 确认当前阶段。数字输入作为另一种选择方式，不改变输出格式。

## 手机界面

在小于 768px 的窗口或粗指针触屏环境中，点击时间按钮打开共享 Modal，依次显示标题、操作说明、两列滚轮、当前预览及取消和确定按钮。字段左侧为当前时间或“选择时间”等占位文字，右侧为时钟图标，正文约 18px。

| 部分 | 显示与选择范围 | 视觉与操作 |
| --- | --- | --- |
| 小时 | `00` 至 `23` | 两位数字，中央项使用主色容器 |
| 分钟 | `00` 至 `59` | 两位数字，独立滚动 |
| 中间分隔 | `:` | 保持时间结构清晰 |
| 时间预览 | `HH:mm` 或“尚未选择时间” | 随临时选择更新，居中显示 |
| 取消 / 确定 | 放在弹窗底部 | 明确区分放弃与应用 |

滚轮每项高 44px，滚动区约 220px 高；上下滑动会吸附到选中项，也可直接点击数值。数字使用等宽排布，选中项有底色和前景色，周围数值使用辅助文字色。小时和分钟分别有可访问标签与当前选中语义。

## 确认与取消

打开弹窗时，以当前有效 `HH:mm` 初始化临时值。当前为空时保持“尚未选择”；圆盘或滚轮的初始位置为零不代表已经选择 `00:00`，手机恢复滚动位置也不会自动把空值写成零点。用户操作后更新临时预览，点击确定才调用表单更新。取消、Escape 或适用的关闭操作保留原值，布局切换也不提交临时值。

零点 `00:00` 是有效时间，与空值分开处理。非必填字段提供“清空”，必填字段不提供清空操作。确定时先验证 `required`、`min`、`max`、`step`，包括跨午夜的允许范围；无效时显示就地错误并保留弹窗供调整。禁用字段不能打开选择器，原表单验证仍保持。

滚轮可聚焦，用上下方向键逐项调整，Home 到第一项、End 到最后一项；选择边界为小时 0–23、分钟 0–59。共享 Modal 保留焦点约束与关闭回焦，预览更新可被读屏感知。

## 隐藏字段与接口格式

原生 `input type="time"` 作为隐藏字段保留，负责字段名、提交值和约束校验。桌面转盘、数字输入和手机滚轮最终都保存两位小时和分钟组成的 `HH:mm`；有效值解析与空值状态分别处理。

新增闹钟将原小时、分钟分开的输入合并为一个时间字段，但保存时仍按原接口拆分为数值：

```ts
{
  hours: Number(time.slice(0, 2)),
  minutes: Number(time.slice(3, 5))
}
```

名称、启停、删除与重复规则保持原有逻辑。重复日期全不选继续提交字符串 `"0"`，表示一次性闹钟。设备设置的所有开始、结束时间复用同一个选择器，已有时段接口和字段名不变。
