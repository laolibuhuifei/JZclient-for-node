## 导航与响应式

全站品牌使用 `JZClientForNode` 与项目原图标。约 80px 的桌面顶栏在页面滚动时吸顶，保留主题切换与账号入口。宽桌面左导航宽 184px；768–1179px 改用 80px 导航栏；小于 768px 使用五个底部导航位置，高 76px 加系统安全区域。导航项为圆角矩形，当前页面使用主色容器。

基础主导航包括主页、聊天、定位、功能、我的、插件，独立“插件”项直接进入管理页 `plugins`。插件总开关开启时，全部有 UI、已加载且未禁用的应用继续追加为独立导航，不限制前四个，桌面和平板侧栏可纵向滚动。手机保留前四项，第五项为带向上箭头的“更多”，向上打开“我的”、“插件”管理和全部可用应用；标题固定，仅列表滚动，高度限定在顶栏与底部导航之间。当前页面属于“我的”、插件管理或插件应用时，“更多”显示选中。浮层支持 Escape、外部关闭与选择后返回触发焦点。

主页“插件”快捷入口直接进入独立管理页，管理和应用导航使用 Puzzle 图标。桌面侧栏与手机“更多”列表把应用名称和“插件”标签放在同一行，名称可省略；768–1179px 方卡把标签固定在图标右上方，图标稍左移留出角标间距，名称居中单行省略，完整名称保留在按钮 title。手机图标保持居中，独立管理项不重复加标签。“我的”移除重复的插件应用板块；旧 `me?panel=plugins` 使用 `location.replace('#/plugins')` 进入管理页，替换历史条目避免后退重复跳转。

手机公共刷新入口放到内容顶部，子页面有返回所属功能组的入口。需要设备选择的业务页把共享 `DeviceWatchPicker` 放到标题右侧，默认两张 64px 高的小矩形卡，超过两台由右侧按钮向下打开其余设备，额外选中设备回显到第二张卡。仅一台固定为桌面 165px、手机 150px 宽；标题保持一行，说明与操作放在下一行。手机信息按钮在卡片右下角，保留 44px，名称省略、状态角标和电量数字分开排列。查看资料不切换设备，点击弹窗“设备详情”才切换并进入概览。主页仍保留两卡，单台最大宽 320px 且靠右。账号失效不展示缓存设备，浮层下方空间不足时按需增加页面末尾留白，关闭或卸载后清理。页脚始终居中保留原 Node.js 吉祥物与 `powered by laolibuhuifei`，作者链接保持原地址。原背景配置与主题切换功能继续生效。

## 主页保留的布局约定

主页标题旁保留小字一言，最右侧三个连接胶囊各有左功能图标和右圆形绿勾/红叉，文字与图标保持固定小间距。胶囊的具体状态由悬停与读屏说明提供。

“我的手表”直接承载两张选择卡与地图，不重复显示当前设备概览。名称超过五个字符或空间不足时省略，完整名称留在悬停与可访问名称中。名称旁的信息按钮打开指定手表的资料弹窗，查看资料不改变当前选择；点击弹窗内“设备详情”才选择该设备并进入概览。

超过两台时，两张主卡缩短，右侧显示竖向圆角箭头与剩余数量按钮，向下打开可滚动的更多手表 Popover。选择额外设备后在第二张主卡回显，被替换设备仍保留在更多列表。

每张主卡自身宽度不超过 170px 时，使用 84px 高的扁卡，隐藏电量环，在右上角显示数字，以圆角边框进度表达电量。边框起点为左上角，电量降低时沿顺时针方向逐段消失。宽度充足时使用右对齐的圆环与中心数字。实际零值显示 `0%`，未知值显示 `—`，不超过 20% 使用警告色。

地图高为宽桌面 480px、中等桌面和平板 400px、手机 320px。横屏至少 1000px 时，运行状态和面板环境排列在右侧，两卡与中间 20px 间隔的总高等于左侧手表卡。窄屏与竖屏将环境放在最后，保持同一份 DOM。

“进程与账号详情”改为向下展开的原生非模态 Popover，在浏览器顶层定位，内容可滚动，父卡片大小保持不变。页面末尾空间不足时按需提供临时留白，并滚动触发按钮，让浮层有可读的向下展开区域；关闭或卸载后清理留白。Escape 或关闭按钮返回触发焦点，点击外部关闭。账号失效时隐藏缓存设备与资料弹窗，浮层内的当前账号和 `mobileId` 也不展示缓存身份。

运行趋势使用 `/api/system` 每三秒成功响应，最多保留最近两分钟的 41 点。首次只显示真实当前数值，形成有效线段后显示曲线，不绘制孤立点或末端圆点；零值有效，缺失读数断线。失败不追加点，恢复后另起线段，短暂一次轮询失败也不会跨中断连线。切换手表保留主机历史，PID 变化或 uptime 回退重新采集。

曲线刷新使用约 420ms 的连续过渡，已有历史平滑左移，新线段从同一连续段的前一个点延伸；当前百分比立即显示真实读数。连续刷新从当前可见位置接续，页面隐藏、图表离开视口或开启“减少动态效果”时直接显示最终位置。未登录或账号失效时，主页连接空态使用账号轮廓图标。

## 公共交互与状态

共享 Modal 挂载到 `body`，限制焦点并支持适用时的 Escape、遮罩与关闭按钮，关闭后返回触发控件。保存和媒体发送期间明确禁用相关控件与关闭权限；权限通过 ref 读取，焦点 effect 只依赖打开状态，因此 busy 状态切换不重置焦点。使用 `:not(:disabled)` 排除被 `disabled fieldset` 连带禁用的输入和按钮。焦点因控件禁用离开时，Tab 会返回弹窗；多个弹窗重叠时，只处理顶层弹窗的键盘交互。

Tabs 使用单个可 Tab 到达的选项，左右方向键、Home 和 End 切换，跳过禁用项。Toggle 使用完整标签提供可访问名称。图标操作有明确名称，焦点保持可见。首次加载、已有内容刷新失败、未登录、未绑定、账号过期和能力不支持各有相应状态。

共享 Select 使用 MD3 单选 combobox 与 Popover/listbox；字段至少 52px，选项至少 48px，当前值有主色容器与勾，活动项单独描边，长值省略，菜单在视口内自动上下定位。隐藏原生 select 保留表单、字段值、ref、required、disabled 和原 change 语义。required 失败时只有表单首个无效字段打开菜单并聚焦按钮，多个必填字段逐项修正。方向键、Home、End 跳过禁用项，前缀输入定位，Enter/Space 提交，Escape 回焦，Tab 继续焦点顺序。详见 [现代化选择控件](../../docs/界面设计/现代化选择控件.md)。

主导航与 Tabs 共用 200ms 滑动选中背景，缓动为 `cubic-bezier(0.22, 1, 0.36, 1)`，指示层由 Web Animations API 驱动且无 CSS 子过渡。快速切换读取当前可见位置后接续；初次和布局变化直接定位，选中项进入滚动区域的可见范围。页面隐藏、指示层离屏或减少动态效果时取消动画，卸载清理动画、观察器与监听。手机指示层对应图标背景，桌面对应导航按钮，不改变原控件的键盘语义。

聊天保留每会话草稿和发送目标捕获，中文输入法确认候选不会触发误发送；轮询使用稳定消息身份和媒体节点。手机会话铺满可视视口，暂时隐藏全局顶栏、底部导航、页面标题、设备选择和页脚；按visualViewport高度和顶部偏移更新，消息独立滚动，输入区在视口底部并保留安全区域。返回恢复列表与外壳，桌面保持两列。录音与媒体资源继续按原逻辑清理。其他页保持既有请求取消、手表切换与错误处理。

手机会话卡至少88px高、头像48px、列表间距10px；列表与消息各自在工作区内滚动，“全部会话”和数量与搜索框同行。IM连接文字和圆形勾/叉在列表/桌面“聊天”标题下，手机全屏会话移到孩子名称下方；已连接为绿色，其余状态写明文字，普通页面标题保留重连和刷新。

宝贝资料与已知设备聊天复用原 `GET /api/watch/:id/avatar`。`/api/chats` 为单聊按收件人 ID 找出手表成员，并以其有效 `accountId` 返回可选 `watchId`；真实资料缺少 `imAccountId` 时也能明确设备身份。只读 `GET /api/chats/avatar?key=…` 优先按该 ID 读取手表资料、签资料 icon，旧成员 icon 保留为回退。同名不会影响匹配，缺少来源时回退人物图标，群聊使用群组图标；取消和设备/会话身份隔离防止迟到图片覆盖当前选择。聊天位置复用 POI 搜索与地图选点，不显示半径；只在外层“发送位置”确认时提交原 location 经纬度与 poi，取消不发送、失败保留。详见 [手机布局与消息状态](../../docs/聊天/手机布局与消息状态.md)。

时间字段可见部分统一为时间按钮：手机或粗指针触屏打开小时、分钟滚轮，桌面打开 MD3 24 小时双环与分钟转盘，可拖动、点击、键盘调整或切换两位数字输入。隐藏原生字段继续校验 required/min/max/step。空值保持尚未选择，`00:00` 有效；确定返回 `HH:mm`，取消保留原值。闹钟接口仍传数值 `hours`、`minutes`，设备设置的开始和结束时间复用该组件。详见 [时间选择说明](../../docs/界面设计/时间选择说明.md)。

页面与设备切换保留约 180ms 的淡入和小幅位移，原生浮层使用短暂进入反馈。轮询不重播切换动画，`prefers-reduced-motion` 下停用相应位移、缩放与切换动画。
