# 外观主题与地图工具

“我的 → 外观”的界面主题区移除当前主题的大色块和胶囊选择条，只保留月亮、太阳两个独立图标按钮。按钮沿用顶栏主题按钮的 44×44px 尺寸和 19px 图标，分别选择深色、浅色，选中的按钮使用主题容器色并设置 `aria-pressed`。默认深色和本地持久化逻辑继续沿用。

共享地图左上角的普通、卫星选项改为地图和卫星图标，悬停说明与可访问名称标明图层，选中底色表示当前选择。右上角加减和回到中心工具栏缩小：桌面按钮 36×36px、图标 18px、容器内边距 3px；粗指针触屏按钮保留 44×44px，便于点击。

地图右下角新增全屏按钮，展开后同一位置显示退出按钮。优先调用浏览器原生全屏；浏览器拒绝或不支持时，使用共享 Modal 铺满页面视口。页内全屏没有额外标题栏，读屏仍能读取“全屏地图”标题；支持 Escape、退出按钮和焦点恢复。全屏退出只返回原地图，原区域编辑弹窗继续保留中心和半径。所有模式保留图层、中心、缩放和范围，不提交区域或发送位置。

地图尺寸变化后重新测量投影，指针坐标继续按已有显示比例换算；手机100%、其他设备90%的规则保持。全屏工具为设备安全区域留出边距。

2026-11-16，正式前端回归64/64、类型检查、构建与差异格式检查通过。新增检查覆盖原生全屏事件、业务禁用时退出、浏览器自行退出、原生拒绝/不支持时的页内回退、Escape和回焦。真实8787的Edge页面检查了深浅切换、主题按钮与顶栏尺寸一致，以及桌面和390×844窄窗口的全屏地图、图层、缩放、范围与返回编辑弹窗。本浏览器原生请求被拒绝，实际浏览器展示验证使用页内回退；原生分支由离线接口事件检查覆盖。本次没有保存真实区域、发送消息或更改背景。

最终构建876.1KiB、897,175字节，SHA-256为`809c53184399d1d72e0faa8cce86098fb25b0d9d776b6bfe6fe9e76bf9e0e5b9`。页内全屏在实际1175×853和390×844视口中均从(0,0)铺满，退出后回焦全屏按钮并保留外层编辑弹窗。最后仅移除全屏卡片进入位移动效和补安全区域边距，正式64项及类型检查沿用同批已通过记录，构建和实际布局随后复核通过。8787可在刷新时直接加载新构建，5173继续热更新。
